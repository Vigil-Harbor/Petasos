# Command reference

Generated by `scripts/generate_reference.py` from the argument parsers in `petasos.hermes.commands` (`_parser` and `install_registered_cli`). Do not edit by hand.

## `petasos`

```text
usage: petasos [-h] {doctor,hermes,config,scanner} ...

Set up Petasos and check that it is protecting a Hermes agent.

positional arguments:
  {doctor,hermes,config,scanner}
    doctor              Say whether Petasos is protecting one Hermes profile, and what
                        to do if it is not.
    hermes              Install Petasos into a Hermes profile.
    config              Work with Petasos settings.
    scanner             Add or remove one scanner's packages in the environment Hermes
                        runs.

options:
  -h, --help            show this help message and exit
```

## `petasos doctor`

Say whether Petasos is protecting one Hermes profile, and what to do if it is not.

```text
usage: petasos doctor [-h] [--home HOME] [--profile PROFILE] [--json] [--verbose]

options:
  -h, --help         show this help message and exit
  --home HOME        Hermes home to use. The default is the one the plugin would use.
  --profile PROFILE  Profile name under that home. 'default' is the home with no
                     profile.
  --json             Print the same report as JSON for a script.
  --verbose          Add paths, versions, and every setting with where it came from.
```

## `petasos hermes install`

Put the plugin in place and turn it on. Running it again updates the files.

```text
usage: petasos hermes install [-h] [--home HOME] [--profile PROFILE] [--dry-run]
                              [--force] [--released] [--run]

options:
  -h, --help         show this help message and exit
  --home HOME        Hermes home to use. The default is the one the plugin would use.
  --profile PROFILE  Profile name under that home. 'default' is the home with no
                     profile.
  --dry-run          Show what would change, and change nothing.
  --force            Replace a plugin directory that is not already Petasos.
  --released         Print Hermes's install command for the published plugin instead of
                     writing files.
  --run              With --released, run Hermes's installer from this Python.
```

## `petasos config`

```text
positional arguments:

    migrate      Show the new settings that match an old petasos: section.

```

## `petasos config migrate`

Show the new settings that match an old petasos: section.

```text
usage: petasos config migrate [-h] [--home HOME] [--profile PROFILE] [--write]
                              [--proceed]

options:
  -h, --help         show this help message and exit
  --home HOME        Hermes home to use. The default is the one the plugin would use.
  --profile PROFILE  Profile name under that home. 'default' is the home with no
                     profile.
  --write            Store the new settings through Hermes. The old section is left in
                     place.
  --proceed          With --write, store the settings even when some old values were not
                     copied.
```
